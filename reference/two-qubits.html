Two qubits

State

Four amplitudes, ordered 00, 01, 10, 11. The left digit is qubit A. Squared magnitudes sum to 1.

Tensor product

ab ⊗ cd = a·ca·db·cb·d

Product or entangled

A product state can be written as a tensor product of one state per qubit. An entangled state cannot.

(1/√2, 0, 0, 1/√2) is entangled: a·c ≠ 0 and b·d ≠ 0 force a ≠ 0 and d ≠ 0, so a·d ≠ 0, but the target needs a·d = 0.

One-qubit gate: the pair rule

Gate on A: apply it to pairs (00, 10) and (01, 11). Gate on B: apply it to pairs (00, 01) and (10, 11). Put each result back in the same positions. This works on entangled states too.

CNOT

A is the control and B is the target. CNOT flips B when A is 1, which swaps the last two amplitudes: (p, q, s, t) → (p, q, t, s). Applying it twice undoes it.

Design move

Start from the target and undo the last gate. Ask what state must exist just before it.
