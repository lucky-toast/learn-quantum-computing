Lesson 4

Build entanglement

Design the circuit that creates the state you proved could not be split.

Your goal. Start from |00⟩ and build (1/√2, 0, 0, 1/√2), then adapt your design to two related targets.

Warm-up

Why one-qubit gates are not enough

You can now apply a gate to one qubit of any state using the pair rule. But |00⟩ is a product state, |0⟩ ⊗ |0⟩, and on a product state the pair rule has a simple effect: it changes only that qubit's factor.[1] For example, X on A gives |1⟩ ⊗ |0⟩ = |10⟩. However many of these you apply, you still have one factor per qubit, so starting from |00⟩ you can never reach an entangled state. You need a gate that makes one qubit's outcome depend on the other's.

A gate that acts on both

Definition The controlled-NOT gate, or CNOT, flips B when A is 1 and does nothing when A is 0.[1] A is the control (●) and B is the target (⊕). In the 00, 01, 10, 11 ordering, that means it swaps the last two amplitudes:

Design it

Try each target on paper first. Gates apply left to right, and the input is always |00⟩.

Name the move

Here is a design habit worth keeping: start from the target and undo the last gate. Applying CNOT twice returns the original state, so you can ask what state must exist just before it. That turns "find a circuit" into a smaller problem.
