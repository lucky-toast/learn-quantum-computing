Lesson 3

One gate, four amplitudes

How to act on one qubit when all you have is a list of four numbers.

Your goal. Apply a gate to just one qubit of a four-amplitude state, including an entangled state that cannot be split into two qubit states.

A and B are the two qubits

A and B are simply names for the two physical qubits. In a result, the left digit is A and the right digit is B, so 10 means A gave 1 and B gave 0.

The pair rule

"H on A" means apply H to qubit A and do nothing to B. Even when A has no state of its own, the list still tells us A's amplitudes for each fixed value of B. So we work in pairs:

Gate on A: pair the results where B matches: (00, 10) and (01, 11).

Gate on B: pair the results where A matches: (00, 01) and (10, 11).

Apply the ordinary one-qubit gate to each pair, then put the results back in the same positions.

Definition This is what the standard notation H ⊗ I means, where I is the "do nothing" gate on the other qubit.[1] The pair rule is that same matrix multiplication, written without the 4×4 matrix.

GateTurns a pair (x, y) into
X(y, x)
Z(x, −y)
H((x + y)/√2, (x − y)/√2)

Worked example, on an entangled state

Apply H on A to (1/√2, 0, 0, 1/√2). B-matching pairs are (00, 10) and (01, 11):

(00, 10): (1/√2, 0) → (½, ½)
(01, 11): (0, 1/√2) → (½, −½)

Returning each value to its position gives:

1/√2001/√2 → ½½½−½ ← 00← 01← 10← 11

We never needed a separate vector for A.

Your turn

First: apply H on A to |00⟩ = (1, 0, 0, 0). Enter 1/√2 as 0.71.

Now an entangled state: apply H on B to (1/√2, 0, 0, 1/√2). Watch which pairs you use.

Work out the gate

Now reverse it. Compare Before and After on paper, decide which pairs changed, and then choose the gate.

Check the idea

The state of an entangled pair cannot be split, but an operation on one qubit still has a precise meaning. You are ready for a gate that acts on both qubits at once.
