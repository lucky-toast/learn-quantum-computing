Lesson 2

Two qubits, four amplitudes

Derive the rule for combining qubits, then find a state that breaks it.

Your goal. Given a list of four amplitudes, work out which state each of two separate qubits must be in, or prove that no such pair exists.

Warm-up from last time

Four outcomes, four amplitudes

Measuring two qubits gives one of four results: 00, 01, 10, or 11. The left digit belongs to qubit A and the right digit to qubit B. A two-qubit state is a column of four amplitudes, one per result, in that order.[1] The squared magnitudes still sum to 1.

Postulate That a joint system is described this way is a rule of quantum theory. It is not something we derive from the math.

The combining rule

Definition If A and B are independent, each of the four amplitudes is the product of one amplitude from A and one from B.[1] This operation is the tensor product, written ⊗:

ab ⊗ cd = a·ca·db·cb·d ← 00← 01← 10← 11

Read it like ordinary independent probability: the amplitude for "A gives 1, B gives 0" is A's amplitude for 1 times B's amplitude for 0. For example, |1⟩ ⊗ |0⟩ has a = 0, b = 1, c = 1, d = 0:

01 ⊗ 10 = 0010 = |10⟩

So |10⟩ is just shorthand for the column with a 1 in the "10" position.

Derive one

Compute |+⟩ ⊗ |−⟩, with A = (1/√2, 1/√2) and B = (1/√2, −1/√2). Enter decimals.

Work backward

Now reverse the rule, which is closer to design. Find the qubit states that produce each target. If you believe no pair can, say so.

Prove it

Trying 16 pairs is not a proof, because a qubit can be in infinitely many states. Suppose (a, b) ⊗ (c, d) equals (1/√2, 0, 0, 1/√2). Then a·c ≠ 0, b·d ≠ 0, and a·d = 0.

A state that cannot be split into separate qubit states is called entangled.[1] You just proved one exists. Neither qubit has a state of its own here, so the four amplitudes describe only the pair.
