# Mission: Quantum Algorithms

## Why
Be able to write a quantum algorithm myself: start from a goal I understand and design something that meets it, without being handed an existing algorithm that already works.

## Success looks like
- Given a small problem I have not seen, I can design a circuit that solves it
- I can explain why the circuit works, using the math rather than analogy
- I can run it on a simulator and confirm that it meets the goal

## Constraints
- Linear algebra is about 6 years rusty. It was strong in college, so it should return quickly with practice and explanation along the way
- Quantum knowledge is at a popular level
- Practice starts with interactive browser lessons, then moves to Python and Qiskit once the ideas are solid

## Out of scope
- Solving open research problems
- Running on real quantum hardware, for now
