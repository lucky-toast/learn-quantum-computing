# Mission: Quantum Computing

## Why
Truly understand quantum computing, long term all of it. For now, cover the basics at the depth of an intro college course. Throughout, be able to write quantum algorithms myself: start from a goal I understand and design something that meets it, without being handed an existing algorithm that already works.

## Success looks like
- I can work through the core of an intro course (states, measurement, circuits, entanglement, the standard algorithms, a first look at error correction) and explain each result using the math rather than analogy
- I read and write the field's standard notation fluently
- Given a small problem I have not seen, I can design a circuit that solves it
- I can run it on a simulator and confirm that it meets the goal

## Constraints
- Linear algebra is about 6 years rusty. It was strong in college, so it should return quickly with practice and explanation along the way
- Quantum knowledge started at a popular level
- No rush. Depth of understanding comes before pace
- Practice starts with interactive browser lessons, and adds Python and Qiskit as a way to check work by hand

## Out of scope
- Solving open research problems
- Running on real quantum hardware, for now
